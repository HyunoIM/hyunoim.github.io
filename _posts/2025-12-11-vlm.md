## Introduction

인간은 세상을 인식하고 이해할 때 하나의 채널만 사용하지 않는다. 시각, 언어 등 여러 채널을 동시에 활용하며, 각 채널은 서로 다른 장점을 가지는데, 시각은 공간적, 구조적 정보를 직관적으로 전달하는 데 강점이 있고, 언어는 개념을 추상화하고 의도를 명확히 전달하는 데 유리하다.

이러한 특성 때문에 인공지능 분야의 목표 중 하나는 시각과 언어를 동시에 이해하고, 사람의 의도를 따라 다양한 실제 작업을 수행할 수 있는 범용적인 assistant를 만드는 것이었다.

---

## Vision 중심 Foundation Model의 한계

최근 몇년간의 연구에서는 vision 모델에 language 정보를 결합한 foundation vision model들이 빠르게 발전해왔다. 이러한 모델들은 분류, 객체 검출, 분할, 캡션 생성뿐 아니라 이미지 생성이나 편집과 같은 작업에서도 뛰어난 성능을 보여주고 있다.  
하지만 이 흐름에는 한계가 있다.

- 각 task는 하나의 대형 vision 모델에 의해 독립적으로 해결  
- task instruction은 모델 설계 단계에서 암묵적으로 고정  
- language는 주로 이미지 내용을 설명하는 수단으로만 사용  

즉, language는 vision 정보를 사람에게 전달하는 역할은 잘 수행하지만, 모델과 사용자가 상호작용하는 인터페이스로서의 역할은 제한적이다.  
이로 인해 이러한 모델들은 인터페이스가 고정되어 있고, 사용자의 다양한 지시를 유연하게 따르기가 어렵다.

---

## LLM의 가능성

한편, Large Language Model(LLM)은 전혀 다른 방향에서 발전해왔다.

LLM은 language를 단순한 출력 수단이 아니라 범용적인 인터페이스로 활용한다.  
사용자는 자연어로 task instruction을 명시적으로 전달할 수 있고, 모델은 이를 이해해 다양한 작업으로 전환할 수 있다.

ChatGPT와 GPT-4의 성공은 instruction-following에 정렬된 LLM이 얼마나 강력한지를 잘 보여준다. 이러한 흐름 속에서 LLaMA를 비롯한 다양한 오픈소스 LLM들이 등장했고,  
Alpaca, Vicuna와 같은 모델들은 machine-generated instruction 데이터를 활용해  
상용 LLM에 근접한 성능을 보여주고 있다.

하지만 중요한 점은, 이 모든 성과가 text-only 환경에서 이루어졌다는 점이다.

텍스트에서 성공한 instruction tuning을 이미지-언어 멀티모달 공간으로 확장할 수 있을까?  
즉, 이미지를 “설명하는 모델”이 아니라 이미지를 보고 지시에 따라 행동하는 assistant를 만들 수 있는가에 대한 질문이다.

---

## Visual Instruction Tuning의 제안

이 논문은 이러한 문제 속에서 Visual Instruction Tuning이라는 개념을 처음으로 제안한다.

핵심 아이디어는 다음과 같다.

- 이미지–텍스트 쌍을 단순한 캡션 데이터가 아니라 instruction-following 형식의 데이터로 재구성  
- ChatGPT / GPT-4를 활용해 멀티모달 instruction 데이터 생성  

이를 통해 범용적인 visual assistant를 학습하는 것이다.

논문에서는 contribution을 네 가지로 정리한다.

1. **멀티모달 instruction 데이터 구축**  
   vision-language instruction 데이터가 부족하다는 문제를 해결하기 위해, 기존 이미지–텍스트 데이터를 instruction-following 형식으로 변환하는 데이터 생성 파이프라인을 제안한다.

2. **Large Multimodal Model (LMM) 제안**  
   CLIP vision encoder와 Vicuna language model을 연결해 instruction-tuned multimodal 모델을 학습한다. 생성된 데이터만으로도 효과적인 학습이 가능함을 실험적으로 보인다.

3. **멀티모달 instruction benchmark 제시**  
   이미지, 지시문, 정답이 함께 구성된 LLaVA-Bench를 제안해 모델의 실제 instruction-following 능력을 평가한다.

4. **오픈소스 공개**  
   데이터, 코드, 모델 체크포인트, 그리고 visual chat demo까지 공개한다.

## Visual Instruction Tuning

### Architecture   

<img src="{{ '/assets/images/vlm0/vlm02.png' | relative_url }}" alt="Image" width="400">   

LLaVA의 목표는 이미 잘 학습된 LLM과 vision model의 능력을 최대한 그대로 활용하면서,  
두 모델을 효과적으로 연결하는 것이다.

LLaVA의 전체 구조는 크게 세 가지로 이루어져 있다.

1. Language Model: Vicuna  
2. Vision Encoder: CLIP ViT-L/14  
3. Projection Layer: vision–language 연결을 위한 선형 변환  

---

### Language Model

Language Model로는 Vicuna를 사용한다. Vicuna는 공개된 LLM 중 instruction-following 능력이 가장 뛰어난 모델 중 하나로, Alpaca, GPT-4-LLM 등의 instruction tuning 결과를 반영한 체크포인트이다.

---

### Vision Encoder

이미지 입력 \( X_v \)는 사전학습된 CLIP ViT-L/14 vision encoder를 통해 시각적 feature로 변환된다.   

<img src="{{ '/assets/images/vlm0/vlm02.png' | relative_url }}" alt="Image" width="400">   

여기서 CLIP encoder는 완전히 frozen 상태로 유지된다. 즉, LLaVA는 vision 표현을 새로 학습하지 않는다.

---

### Projection Layer: Vision → Language

LLaVA에서 실제로 학습되는 핵심 모듈은 vision feature를 language embedding space로 옮기는 projection layer 하나이다.   

<img src="{{ '/assets/images/vlm0/vlm03.png' | relative_url }}" alt="Image" width="400">   

projection matrix \( W \)를 사용해 CLIP vision feature \( Z_v \)를 language embedding 차원의 token으로 변환한다.

이렇게 얻어진 \( H_v \)는 LLM 입장에서 텍스트 token과 동일한 차원을 가지는 visual token이 되는 것이다.

이 projection 방식은 빠른 데이터 중심 실험이 가능한 lightweight 구조이기 때문에 매우 간단하다.

---

## Training   

<img src="{{ '/assets/images/vlm0/vlm04.png' | relative_url }}" alt="Image" width="400">   

각 이미지 \( X_v \)에 대해 위와 같은 multi-turn 대화 데이터가 생성된다. \( T \)는 총 턴의 수이다.  
\( t \)번째 턴의 명령을 다음과 같이 처리한다.   

<img src="{{ '/assets/images/vlm0/vlm05.png' | relative_url }}" alt="Image" width="400">   

첫 번째 turn에서는 이미지와 질문의 순서를 랜덤하게 배치하는데, 이는 모델이  
이미지와 언어 입력 순서에 과도하게 의존하지 않도록 하기 위함이다.

이후 turn부터는 텍스트 질문만을 instruction으로 사용한다.

학습은 LLM의 기존 autoregressive objective를 그대로 사용한다. 길이 \( L \)의 sequence에 대해 타겟 답변 \( X_a \)에 답할 확률을 다음과 같이 계산한다.   

<img src="{{ '/assets/images/vlm0/vlm06.png' | relative_url }}" alt="Image" width="400">   

모델은 assistant의 답변 token만을 예측하며, 이전 instruction과 모든 과거 대화가 조건으로 주어진다.  
또한 모든 답변은 항상 이미지에 grounding되어 있다. 즉, 이미지 정보는 모든 turn에서 condition으로 작용한다.

---

### Stage 1: Pre-training for Feature Alignment

vision feature를 LLM의 embedding space에 정렬시키는 단계이다.  
입력 이미지 \( X_v \)가 주어지면 “이미지를 간단히 설명하라”와 같은 질문 \( X_q \)를 랜덤하게 샘플링한다. 이때 정답 \( X_a \)는 기존 caption 그대로 사용한다.

즉, 이 단계에서는 기존 image-caption 데이터를 instruction-following 문제로 바꾸는 단계이다.  
여기서 학습되는 파라미터는 projection matrix \( W \) 하나뿐이다.

---

### Stage 2: Fine-tuning End-to-End

이 단계에서는 실제 Visual Instruction Following 능력을 학습한다. 여기서도 vision encoder는 frozen 되지만 projection layer와 LLM이 함께 fine-tuning된다.

두 가지 시나리오로 이루어진다.

#### Multimodal Chatbot   

총 158K 규모의 이미지–언어 instruction 데이터를 사용하고 세 가지 응답 유형을 포함한다.

- multi-turn conversation  
- single-turn description  
- single-turn reasoning  

학습 시 세 유형을 균등하게 샘플링하는 멀티모달 챗봇 시나리오이다.

#### Science QA

ScienceQA는 이미지 또는 텍스트 context를 포함한 과학 문제를 다루는 대규모 멀티모달 데이터셋이다.  
\( X_{instruction} \)는 질문 + context (텍스트 또는 이미지), \( X_a \)는 답변으로 이루어진다.  
이 실험은 이미지 기반 추론 과정을 자연어로 생성할 수 있는지를 평가하는 데 목적이 있다.

## Experiments

모든 실험은 8× A100 GPU 환경에서 수행되었으며, 학습 설정은 Vicuna의 하이퍼파라미터를 따른다.

---

### Multimodal Chatbot   

<img src="{{ '/assets/images/vlm0/vlm07.png' | relative_url }}" alt="Image" width="400">   

LLaVA가 이미지를 이해하고 대화를 이어갈 수 있는지 정성적, 정량적으로 평가한다.

다른 모델들과 비교했을 때, LLaVA가 단순히 이미지를 설명하는 것이 아니라  
질문의 의도를 이해하고, 그에 맞는 응답을 생성한다는 점을 볼 수 있다.   

<img src="{{ '/assets/images/vlm0/vlm08.png' | relative_url }}" alt="Image" width="400">   

COCO validation 이미지 30장을 선택해 각 이미지마다 세 종류의 질문을 생성한다.

- Conversation  
- Detailed Description  
- Complex Reasoning  

총 90개의 질문으로 구성되며, instruction 데이터 구성 방식에 따른 성능 변화를 분석한다.  
reasoning 능력의 향상이 conversation 성능도 함께 끌어올린다는 점을 볼 수 있다.   

<img src="{{ '/assets/images/vlm0/vlm09.png' | relative_url }}" alt="Image" width="400">   

실내, 실외 장면, 밈, 그림, 스케치 등 다양한 도메인의 이미지 24장을 수집한다.  
각 이미지에는 매우 상세한 설명과 정제된 질문이 함께 제공된다.

복잡한 reasoning 질문에서 text-only GPT-4(정답 설명 제공) 대비 81.7%라는 높은 성능을 기록한다.

## Limitations   

<img src="{{ '/assets/images/vlm0/vlm010.png' | relative_url }}" alt="Image" width="400">   

위처럼 음식 사진에서 가게 이름을 맞추는 문제, 냉장고 사진에서 요거트 브랜드, 맛을 구분하는 문제와 같은 문제들은 고해상도 이미지 이해, 방대한 외부 지식, 언어, 문화적 맥락이 동시에 요구된다.

LLaVA가 이미지 내 딸기를 보고 “딸기 요거트가 있다”고 잘못 판단하는 상황이 보인다.  
LLaVA가 때때로 이미지를 의미 단위가 아닌 patch의 집합으로 인식한다는 한계를 드러낸다.

## ScienceQA   

<img src="{{ '/assets/images/vlm0/vlm011.png' | relative_url }}" alt="Image" width="400">   

두 번째 실험은 멀티모달 reasoning 능력을 정량적으로 평가한다.

LLaVA가 90.92% 정확도를 달성하며 SoTA 모델에 근접한 성능을 보인다.

또 주목할 점은,

- GPT-4가 답변을 못 하는 경우 LLaVA 결과 사용하는 GPT-4 complement는 성능 변화가 크게 없고  
- GPT-4와 LLaVA 답변이 다를 경우 GPT-4가 두 답변을 보고 최종 판단하는 GPT-4 as Judge는 정확도가 올라갔다  

이미지를 볼 수 없는 text-only GPT-4가 이미지 context가 있는 문제의 성능을 개선했다는 점을 주목할 점이다.

---

## Conclusion

이 논문은 Visual Instruction Tuning이 실제로 효과적인 학습 패러다임임을 실험적으로 보여준다는 점에서 의미가 있다.

이미지–텍스트 데이터를 단순한 캡션 데이터가 아니라, instruction-following 형식의 멀티모달 데이터로 재구성하는 파이프라인을 제안했고, 이를 기반으로 LLaVA라는 멀티모달 모델을 학습했다.

- 멀티모달 모델의 성능 향상은 복잡한 구조 설계보다 instruction 데이터와 학습 방식에 크게 의존  
- LLM이 가진 instruction-following 능력은 vision 입력이 추가되더라도 효과적으로 확장될 수 있다  

이 점이 이 논문을 통해 주목해야할 부분인 것 같다.
